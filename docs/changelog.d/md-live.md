### Added

- **Live view for markdown files.** A new Live mode lets you edit a markdown
  file while it looks formatted: headings, bold and italic, links, bullet and
  task lists, quotes and GitHub alerts, code blocks and images appear as they
  will read, and the markdown symbols show only on the line you are editing.
  Task checkboxes can be ticked with a click, and Ctrl+click (⌘+click on a
  Mac) opens a link. The file itself is saved exactly as you typed it.
