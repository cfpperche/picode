### Added
- **Muse Code and Antigravity in Agent CLIs.** The catalog lists Meta's `muse`
  and Google's `agy`: installed or not, Check setup, — for Muse Code — Check
  for updates against its release channel, and **New terminal**, which runs
  the CLI in a PiCode terminal with its own defaults. There are no launch
  settings, no session list and no activity state for these two yet. Both
  wear their vendor's mark (Meta, Antigravity) wherever the CLI appears.

### Changed
- Agent CLIs describe what a row can do as capabilities: a CLI can open a
  terminal without carrying activity, launch settings or sessions.
