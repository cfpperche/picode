### Added

- **Automations and Outcomes: OpenCode, Grok and Hermes now have a cost.**
  PiCode prices their conversations — OpenCode's and Hermes' own stores,
  Grok's session folder — so a scheduled start run on these CLIs shows its
  cost and stops at its cost limit, and a removed agent's Outcomes row says
  what it spent. A turn the CLI recorded as free on a model PiCode has no
  price for does not count toward a cost limit; the editor says so.
