# Study: reusable prompt/command templates (Snippets)

- **Date:** 2026-09-13
- **Scope:** on-demand user templates with placeholders, invoked into
  managed Pi agents, Agent CLI terminals, and plain shells.
- **Adaptation:** [ADR-0130](../decisions/0130-picode-snippets.md),
  [architecture/snippets.md](../architecture/snippets.md).
- Closed-source claims are **inference**.

## Who we studied

| Product | Store | Placeholders | Shell? | Take | Refuse |
|---|---|---|---|---|---|
| Cursor Commands → Skills | `.cursor/commands/` | Extra text appended, not interpolated (**inference**) | No | Composer `/` invoke UX | File-only store |
| Claude Code | `.claude/commands/` | `$ARGUMENTS`, `$1` | `` !`bash` `` at expand | Argument *intent* | `` !`cmd` `` / `@file` |
| Copilot prompt files | `.github/prompts/*.prompt.md` | `${input:name}` | No | Named fill sheet | `${…}` syntax (shell `${VAR}`) |
| Pi templates | `~/.pi/agent/prompts/*.md` (already wired) | `$1`, `$@`, `${1:-default}` | No | Keep in parallel | Becoming PiCode's source of truth |
| OpenCode | `.opencode/commands/` | `$ARGUMENTS`, `$1` | `` !` `` | — | Writing that directory |
| Warp Workflows | Drive + YAML | `{{argument}}`, default, enum | **Yes** | Brace syntax, fill-then-paste | Cloud sync; silent Enter on prompt→shell |
| t3code / paseo / Cursor bar | — | — | — | Fill-then-send; one library / many runtimes | Vendor SDKs (ADR-0003); collapsing CLIs into `agents` (ADR-0069) |
| Devin Automations | — | — | — | — | Wrong analog (that's ADR-0045) |

## PiCode adaptation

GUI-owned SQLite library (`internal/snips`). Expand inside PiCode.
`{{name}}` not `$1`. Host page, not an app. Snippet-run door is new;
