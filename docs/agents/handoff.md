# Handoff notes and the board

> Reference for [AGENTS.md](../../AGENTS.md) non-negotiable 1. AGENTS.md keeps
> the rules; this file keeps their detail.

**Every session that changes state leaves one note in
  `docs/handoff/<date>-<branch>.md`** (≤ 25 lines, written from
  `make close-summary`). Its optional `## Next up` / `## Debts` sections
  reach the board for **7 days, one bullet each** (ADR-0145); a durable
  item goes to `docs/handoff/open/<topic>.md`, which is also where a debt
  is paid — flip `- [ ]` to `- [x]` in the file that owns it, never delete
  another session's line. The board renders **two `## Next` bullets per
  topic** plus a pointer, counts only **open** debts, and over its target
  it warns and still renders: `make close` is never blocked by how much
  the team wrote down. **`docs/handoff.md` is generated by `make handoff`
  and is not in git** (ADR-0123) — never edit it, and the pre-commit hook
  refuses a committed copy, on `main` and in a worktree.
  A fact that only exists **after** the merge — the owner confirming it
  live, a debt paid by observation — is one commit on `main` that amends
  the note or topic file it corrects: no worktree, no branch, no gate run
  (ADR-0149). A *new* note still belongs to the branch it records.
  Shipped work is `git log`, the ADR index and the changelog — never
  handoff prose. Deployment history is `var/deploy-log.jsonl` in the
  data dir (`~/.picode` by default).
