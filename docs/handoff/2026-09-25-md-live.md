# 2026-09-25 — feat/md-live: Live view for markdown (live preview in the editor)
Shipped: Preview · Live · Split · Raw for markdown in the desktop/browser file pane.
Live is Obsidian-style live preview inside CodeMirror: the buffer stays the file's
own text (saving never reformats); syntax shows only on lines a selection touches,
and only while the editor is focused. Live is a Compartment of the same editor, so
Raw↔Live keeps cursor and undo history; remembered in `picode-md-view`. Both apps'
fileLang now use `markdownLanguage` (GFM). Phone has no Live.
Mechanism: web/browser/src/lib/mdLivePlan.js (planLive, activeLines, headingPos;
10 tests, no DOM); web/browser/src/lib/mdLive.js is a ViewPlugin plus widgets: the
task checkbox toggles `[ ]`/`[x]`, Ctrl/⌘+click follows links, a plain click only
places the cursor. CSS under `.cm-md-live` in web/browser/src/styles/app.css.
Tables, HTML, math and frontmatter stay as monospace source.
