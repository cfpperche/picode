# 2026-09-17 — computer-m0: foundations for the computer tool (ADR-0148, proposed)

Direction set by the owner today, after the benchmark study
(`docs/benchmarks/2026-09-16-computer-use.md`): capability first — one grant
per agent or CLI, the 23 desktop actions unrestricted, policy refinements
later in the owner's order. ADR-0148 records it (proposed, awaiting the
owner's read); `docs/plans/computer-use.md` carries the spec and M0–M5.

Landed (three commits): `internal/grant` holds the ADR-0143 identity rule
(agent id → `term:<id>` → nothing); the browser delegates to it, callers
untouched. The hub's `Command` gains optional `Kind`, `Principal` and a
per-command `Timeout` (not on the wire): browser frames are byte-identical and
a page without `Kind` still fails closed through the CDP catalog. `browser
screenshot` returns a pi image block (`imageBlock`, tested), not a temp path.

Verified: `go test ./internal/grant/ ./internal/browser/ ./internal/server/`,
`node --test packages/pi-browser/test/*.test.ts` (12), `make ci-scoped`.
