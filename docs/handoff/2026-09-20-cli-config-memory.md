# 2026-09-20 — cli-config-memory: native Settings and native Memory for every agent CLI

Implemented: ADR-0163 — Settings stops being Pi-only. The eight guest CLIs are edited through their own config files by one generic driver plus a per-CLI declaration (paths per scope, document format, a field list keyed on the vendor's own dotted names); a write splices the bytes of exactly one scalar, so comments, key order and every key PiCode does not know survive a save, and a save built on an older read answers 409 instead of overwriting what the CLI wrote in the meantime. Memory is a new pane for all nine, in four declared tiers: editable, readonly, none, unknown.
Verified live on a `qa-scratch` instance, not only in tests: a save on Codex's real `config.toml` changed one line and nothing else; add-then-reset round trips on OpenCode's JSONC and Claude Code's `settings.json` came back byte-identical; a PiCode worktree resolved to its repository's Claude Code memory folder; the Grok and Codex write/delete refusals held; secret masking applied on read with the file untouched; path traversal was refused.
What the verification caught, which is this note's value: the add-then-reset round trip over fixtures shaped like the real files found an emptied `[memories]` table and an emptied `memory:` block left behind; live inspection found that with no workspace open the project layer vanished silently, so a `?layer=project` link edited the machine file; JSON inserts put the comma alone on its own line and JSON removals glued the closing brace to the member above; visual review found a 28px segmented control beside a 36px filter, one danger sentence printed twice in a group, an unset boolean rendering as "Off" where the CLI's default is On, an editable box pixel-identical to the read-only one, and a filter over an empty list.
A CSS block was shared between the desktop and mobile stylesheets by slicing at a marker, and a second slice deleted 190 lines of mobile-only rules; nothing but a phone-width screenshot caught it, and the mobile file was restored from HEAD. That is why every mount gets exercised, not only the one being edited.
visual-review: two passes. The second reported nine of ten earlier findings fixed; the two it still failed on — a sentence printed twice in one row, and phone captures that did not reach the states they were meant to prove — were fixed and re-captured afterwards.
State: `make close` green (fmt, vet, hooks, Go, test-js, build, docs over 48 changed paths), `main` can fast-forward to `feat/cli-config-memory`.
Debts from this branch stay in `docs/handoff/open/agent-clis-native.md` — Omp's probed memory folder, Antigravity's unknown tier, machine/workspace layers only, no physical-device acceptance for the mobile panes.
