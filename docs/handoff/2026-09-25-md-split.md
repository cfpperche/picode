# 2026-09-25 — feat/md-split: Split view for markdown, with scroll sync
Shipped: Preview · Split · Raw for markdown in the desktop/browser file pane.
Split hides below an 880px pane body and falls back to Preview; the last view
is remembered in localStorage `picode-md-view`. Mobile has no Split.
Mechanism: `rehypeSourceLines` / `withSourceLines(offset)` stamp `data-line` on
blocks, offset by `splitFrontmatter`'s new `bodyLine`; web/shared/domain/scrollSync.js
does the pure interpolation (with tests); web/browser/src/lib/useSplitSync.js syncs
editor↔preview with 120ms echo suppression, and re-renders re-sync to the editor.
Double-click on a preview block puts the cursor on its line, level with the block.
MarkdownDoc renders from `useDeferredValue` text.
