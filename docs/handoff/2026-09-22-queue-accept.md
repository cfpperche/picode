Slice 1 landed with it: migration `066_delivery_queue.sql` and `internal/store/delivery_queue.go` — the same mechanics the declarations proved (JSON body as the row's truth, byte-for-byte receipts in `delivery_queue_requests`, row + `delivery.changed` in one transaction, the delivery mutex serializing both stores), states `waiting → authorized → running → done | failed` plus `withdrawn`, one active entry per delivery, and `order`/`authorize` refused for any actor but `store.OwnerActor` so the owner's authority survives a door that forgets to check.
