# 2026-09-23 — feat/agy-login: Antigravity signs in through the GUI

Shipped: ADR-0197 (owner: option (a)). Measured on Antigravity 1.2.9:
- there is no login command, and `GEMINI_API_KEY` is ignored;
- print mode offers Google's page and takes a code, **only with a terminal on stdin**, **within 60s**, then runs its prompt.

`internal/server/agy_login.go` runs `agy -p . --print-timeout 1s` under `script -qfec` and returns the page (`POST`/`GET`/`DELETE /api/agy/login`, `POST /api/agy/login/code`). It:
- passes the pasted code in;
- kills agy **when the token file holds a login**, before the prompt runs. `killAgyTree` finds agy among script's children, because script puts agy in a session of its own;
- gives agy do-nothing `xdg-open`/`sensible-browser`/`www-browser`/`gio`, since otherwise it opens a real browser on the PiCode machine;
- files a login already present in the vault and sets it aside, putting it back on failure or cancel;
- refuses while Antigravity terminals run.

`AgyLoginDialog.jsx` (browser and mobile) opens on its one door: Google's page, a code field, the 60s countdown (it starts when the page is shown), and "Get a new link". There is no terminal door, because Antigravity has none.

Verified: `make ci-scoped` PASS. `TestAgyGUILogin` runs a fake agy under the real `script`. It covers:
- the present login set aside, and restored after a refused code, whose message is the refusal, not the window closing;
- no real `xdg-open` on agy's PATH;
- cancel killing agy itself;
- a good code stopping agy long before its prompt ends, then filed in the vault.

Scratch QA with the real Antigravity and an isolated HOME (no Google sign-in, fake codes). The first pass was FAIL: a wrong code read as a timeout, cancel left agy alive for its 60s, and agy opened a real browser. All were fixed; the recheck PASSED with 0 agy processes within 1s of cancel, no browser, the countdown starting at 60s, and the owner's token untouched.
visual-review: PASS (agl2-a-error.png, agl2-b-restored.png, agl2-c-m-waiting.png, agl-2-waiting.png; card 5/5)

Not verified: a real Google sign-in end to end. There is still a narrow race between the token landing and print mode's prompt; the prompt is "." capped at 1s. A login with no `id_token` collapses into the vault's single unnamed row.
