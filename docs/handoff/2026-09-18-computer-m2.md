# 2026-09-18 — computer-m2: an agent can use the computer, end to end

ADR-0148 M2 (`docs/plans/computer-use.md`). The path from a pi tool call to
the shell's desk thread exists: `pi-computer` → `POST /api/computer/tool`
(identity by `internal/grant`, one grant per principal in
`computer.policy.<key>`, the closed catalog of 23) → a `kind:"computer"`
frame on the ADR-0132 line → `computer_call` in the shell → the answer back
as an image block or lines. Every call leaves a `computer.step` event;
Settings ▸ Computer shows one switch per agent or terminal and the recent
steps; the page mirrors the enabled keys into the shell.

Verified here: Go tests per decision row (identity, grant, unknown action,
frame on the wire, audit row with the image hash, terminal principal, no
shell, list/save/revoke), the JS suites (channel dispatch by kind, runner,
grants mirror, package summarizers, the 23-literal check), `make web`.
Not verified: a real agent driving a real desktop — that run is the owner's
(deploy, install `packages/pi-computer` for one agent in the "This agent"
scope, switch it on in Settings ▸ Computer, ask it to open Notepad and type).
