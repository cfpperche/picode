# 2026-09-18 — computer-m1: the actuator in the shell and the Computer lab

ADR-0148 M1 (`docs/plans/computer-use.md`). The shell can now see and drive
the desktop behind a per-principal grant the page mirrors in M2. A "desk"
thread (COM MTA, per-monitor DPI, one action at a time) runs the 23 actions:
screenshot of a monitor or a window (GDI + WIC, ≤ 1280 px PNG plus a JPEG
preview), zoom, UIA snapshot, cursor, wait, windows, focus, clicks, drag,
scroll, type, key, hold_key, clipboard, open. Coordinates are pixels of the
last image; `geometry::Frame` maps them back. Pure modules (geometry, keys,
b64, axfmt) carry 32 tests: `rustc --edition 2021 --test src/lib.rs`.
No new crate. Verified: cross `cargo check`, `make desktop-shell`, the pure
tests. Nothing was run on a real desktop yet.

Lab: tray ▸ Computer lab (principal `lab`): screenshot, click where you
point (red crosshair = the page's mapping, green ring = the cursor the desk
saw afterwards), drag to zoom, type, key, scroll, snapshot, clipboard, open.
Keep it on another monitor: clicks land on the real screen.
