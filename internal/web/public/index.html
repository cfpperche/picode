PiCode is a browser-based Agent Development Environment for Pi coding agents: create, configure and orchestrate agents across workspaces — with the real Pi TUI always one tab away.

This is the M0 bootstrap. Start the dev server with make dev and follow docs/handoff.md in the repository.
