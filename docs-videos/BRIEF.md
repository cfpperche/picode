# PiCode docs tutorials

Three short tutorials, one per guide, all built from the same grain:

1. **create-an-agent** — embeds in `guide/getting-started`. Arc: name the promise → show the real dashboard → the new-agent form → the agent running → hand back to the docs.
2. **automate-it** — embeds in `guide/automations`. Arc: the promise → the automations list → the detail (schedule/webhook) → a run landing in the inbox → the payoff line.
3. **take-it-anywhere** — embeds in `guide/mobile`. Arc: the promise → phone fleet → phone agent → phone inbox → "same server, same agents".

## Non-negotiables (from the repo contract)

- **Parity**: every UI image is a real capture of the seeded fixture daemon
  (`cmd/picode-docs-fixture`) taken by `scripts/docs-video-stills.mjs` from the
  current working tree. No hand-drawn UI, no invented screens.
- **House tokens** (from `web/src/styles/app.css` and the docs theme):
  bg `#0e0e11`, panel `#16161c`, border `#26262e`, text `#e6e6f0`, muted
  `#9b9ba7`, accent `#7c8cf8`, accent-2 `#2f6fed`. Monospace: JetBrains Mono
  (bundled in `assets/fonts/`), sans: system-ui.
- **Silent by design**: docs videos are watched muted; captions carry the copy.
- Deterministic renders; GSAP paused timeline per composition.

## Assets

- `assets/stills/*.png` — generated; regenerated by the pipeline, never edited.
- `assets/fonts/jetbrains-mono-*.woff2` — JetBrains Mono (OFL license), bundled.

## Customizations

- Canvas 1280x720 @ 30fps; durations: V1 17s, V2 17s, V3 15.5s.
- Output: `renders/<id>.mp4` → copied to `www/videos/` by the Makefile target.
