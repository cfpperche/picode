# PiCode Chrome extension

Sideload this folder in Chrome (`chrome://extensions` → Developer mode →
Load unpacked). Then register the native host:

```bash
picode extension-install          # Chrome running on Linux/macOS
picode-desktop extension-install  # Chrome on Windows, PiCode in WSL
```

User guide: https://cfpperche.github.io/picode/guide/browser-extension
