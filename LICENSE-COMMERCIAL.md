# Commercial / Enterprise license

PolyForm Noncommercial 1.0.0 does **not** cover commercial or enterprise
use. That includes internal use at a company.

To obtain a license:

1. Open a GitHub issue on [cfpperche/picode](https://github.com/cfpperche/picode)
   with the subject `Enterprise license`.
2. Include organization name, intended use (internal ADE / hosted / number
   of seats if known).
3. Use is not granted until a **signed** agreement is in place.

Until then, do not use this software commercially.

This file is a **notice**, not the enterprise contract. Pricing, liability,
support, and governing law live in that signed agreement — draft it with
a lawyer.
